Quickly find mentions of a keyword in the current conversation with highlighted matches.

Run this command:
```bash
python3 "${CLAUDE_PLUGIN_ROOT}/search_helper.py" find $ARGUMENTS
```

After output appears, use Ctrl+Shift+F and search `CS-ANCHOR-FIND` to navigate here.
